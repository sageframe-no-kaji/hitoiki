Hitoiki 1.0.1 says that it started.

The first time Hitoiki opens, a welcome window says that it is running and shows the shortcut that opens the panel, `Control-Command-Space` unless you changed it. It shows once. If another app or macOS already holds the shortcut, the window says so and offers to change it.

The menu bar item is now on by default, so Hitoiki's icon is in the menu bar. If you turned it off, it stays off.

Hitoiki needs macOS 14 or later. Get the signed, notarised app from [hitoiki.sageframe.net](https://hitoiki.sageframe.net), or build it from source, free under the MIT license.

When Hitoiki opens, and once a day, it asks GitHub for the latest version number, sending only its name and version. You can turn this off in settings.

Read the [README](https://github.com/sageframe-no-kaji/hitoiki#readme) for how to use it and how to build it.
