# ho-06.2.2 — Second fix pass for The Audit

ho-06.2x run 2 returned ho-06.2 with one Must-fix finding and no other. Everything ho-06.2 and ho-06.2.1 state still binds; where they differ from this one, this one does.

## Problem

From `ho-process/reviews/ho-06.2x-report-2.md`: **M1.** ho-06.2.1's invariant 1 says a test wait that times out names "its place in the test file—and what it was waiting for". The named fixture waits (`ran`, `running`, `done`, `transcriptContains`, `alive`, `end`, `reach`) give both. The 34 direct `Fixture.until { … }` calls give their place and the default phrase "the condition written there", not the condition in words.

## The practitioner's ruling, 2026-11-14

A direct wait names itself by its line, and that line is its condition: the timeout's location leads straight to the code that states what was awaited. A phrase beside each of the 34 calls would restate the code next to it, a duplication the audit's standard removes. ho-06.2.1's invariant 1 now reads:

> **A test wait that times out names itself.** When a fixture wait gives up, the failure names its place in the test file. A named wait also says in words what it was waiting for; a direct `until { … }` names its line, where the condition is written. No test's timeout changes length.

## Solution

No code changes. This document records the ruling and restates the invariant.
